# Игры на двоих

Одиннадцать игр в браузере: с ботами, на одном экране или онлайн с друзьями.

Играть: https://mdgames153.web.app/

Зеркало GitHub Pages: https://maximdibrova-netizen.github.io/TicTacToe/

## Firebase и аккаунты

Проект Google Firebase: `mdgames153`. На главной есть необязательный вход через
Google или почту, регистрация, смена имени, выход и восстановление пароля.
Сессию и данные аккаунта хранит Firebase Authentication. Играть и создавать
комнаты можно гостем; сохранённые партии и настройки игр пока остаются на
устройстве, а обмен ходами по-прежнему идёт через PeerJS.

Исходники аккаунта — `src/account/`, публичная конфигурация — `config.js`.
`getAnalytics` не подключён. Firebase SDK 13.2.0 собирается локально через
`build-account.mjs` в `account.js`; браузеру не нужен npm или внешний CDN SDK.
Вносите изменения в `src/`, затем запускайте `python build.py`, чтобы обновить
страницы GitHub Pages. Сгенерированные HTML, `account.js` и `game-rating.js` вручную не редактируются.

Для публикации установите зависимости (`npm ci`) и Firebase CLI
(`npm install -g firebase-tools@15.35.0`), выполните `firebase login`, затем
`npm run deploy:firebase`. Команда собирает только публичные файлы в
игнорируемую папку `firebase-public/`, публикует их, правила Firestore и индексы. Конфигурация `firebase.json`
сохраняет отдельные адреса всех игр; исходники, тесты, node_modules и файлы CLI
в публикацию не включаются. Пароли и учётные данные CLI в репозиторий не входят.
Способы входа включены в Authentication; разрешённые домены — `mdgames153.web.app`,
`mdgames153.firebaseapp.com` и `maximdibrova-netizen.github.io`.

Проверки: `npm test`; в отдельном терминале `npm run emulator:auth`, затем
`npm run test:account`. Последняя проверка использует настоящий Firebase SDK
с локальным эмулятором: регистрация, вход, сохранение сессии, профиль,
восстановление доступа, Google-вход и гостевая игра без сети.
Параметр `?authEmulator=9099` действует только на localhost/127.0.0.1;
публичный сайт всегда подключается к настоящему Firebase.

## Рейтинг и игры одновременно

Рейтинг хранится в Cloud Firestore Standard, база `(default)`, регион
`europe-west3` (Франкфурт), бесплатная квота Spark. Создание базы не включает
платный тариф. Начало — 1200, алгоритм Glicko-1, первые 10 партий предварительные
(знак `?`). Учитывается неопределённость рейтинга, поэтому первые изменения
могут быть большими. Это собственные настройки, не точная копия Chess.com.
Рост неопределённости после длительного отсутствия пока не реализован.

У каждой из 11 игр отдельный рейтинг: варианты и контроли времени внутри игры
используют один рейтинг. Ещё два независимых рейтинга — за связки из трёх и
четырёх игр. Связка не изменяет рейтинги отдельных игр. Все рейтинги, лидеры
и последние 20 результатов доступны по кнопке «Мои результаты» на главной.
Лидеры включают предварительные рейтинги. В публичных профилях показывается
имя игрока, адрес почты в рейтинг не передаётся.

Для рейтинговой партии каждый участник входит в свой аккаунт и подтверждает
игру на рейтинг до первого хода. Часы и ходы ждут облачного подтверждения.
Боты, игра на одном устройстве, анализ, продолжение с выбранной позиции и
партии с подсказками не меняют основной рейтинг. Сила ботов помечена `≈`:
это ориентировочная оценка уровня сложности, без калибровки по людям.

В общей комнате можно выбрать 3 или 4 разные игры из семи: точки, крестики-нолики,
го, шашки, морской бой, Коридор, Лава. Оба игрока согласуют набор и рейтинговый
режим. На компьютере доски стоят сеткой, на телефоне переключаются вкладками;
скрытые доски продолжают работать. За победу на доске даётся 1 очко, ничью —
0.5, поражение — 0. Общий результат определяется суммой после всех досок.
В режимах на 3–4 человека рейтинг пересчитывается по попарным результатам:
победитель выше проигравших, равные места считаются ничьей между собой.

Результат подтверждают клиенты всех участников. Правила базы проверяют
согласие, формулу Glicko и одновременное изменение всех рейтингов, запрещают
повторный зачёт и произвольную запись чисел. Ходы остаются в PeerJS: отдельного
сервера проверки ходов и античита здесь нет. Если участник закроет игру или
откажется подтверждать результат, партия может остаться без зачёта. Обновление
страницы хозяина прерывает текущую комнату; не обновляйте её во время партии.

Исходники: `src/ratings/`, общий цикл партии `src/shared/game-events.js`,
адаптеры `src/<игра>/match.js`, связки — `src/hub.html`.
Данные: `ratingPools/{pool}/players/{uid}`, `ratingProfiles/{uid}`,
`ratedMatches/{id}` и проверочные документы `checks/{uid}`. Правила —
`firestore.rules`, индекс истории — `firestore.indexes.json`.

Проверки перед публикацией:

```sh
npm ci
npm run build
npm test
# В отдельном терминале:
npm run emulator:ratings
# После запуска эмуляторов:
npm run test:account
npm run test:ratings
npm run test:multi
npm run test:events
```

Эмуляторы рейтингов используют Auth 9099 и Firestore 8080. Тесты правил и
хранилища изолированы в отдельных demo-проектах. Параметры
`?authEmulator=9099&firestoreEmulator=8080` работают только на loopback.

Обычное обновление по-прежнему выполняется одной командой
`npm run deploy:firebase`; перед ней запускаются проверки. Деплой заменяет код,
но не удаляет аккаунты и рейтинги. При изменении структуры данных нужно
согласованно менять клиент, правила и при необходимости миграцию. Push в GitHub
обновляет зеркало GitHub Pages, Firebase публикуется отдельной командой.
При одновременной работе сначала получите изменения друга (`git pull --rebase`),
затем соберите файлы и проверяйте итоговую версию; не используйте force push.

Бесплатный план ограничен квотами, а не гарантированными «100 игроками».
У Firestore сейчас 50 000 чтений и 20 000 записей в сутки на проект, 1 GiB
хранения; экран лидеров и подписки тоже расходуют чтения. Ходы по PeerJS
не записываются в базу на каждом ходе. Контролируйте раздел Usage в Firebase.
Актуальные лимиты: [Firestore](https://firebase.google.com/docs/firestore/quotas),
[Hosting](https://firebase.google.com/docs/hosting/usage-quotas-pricing).

## Комната

На главной нажми «Создать комнату» и отправь другу одну ссылку. Дальше любой из вас выбирает игру,
и она открывается у обоих. Чтобы переключиться на другую игру, новый код не нужен.

## Разбор и подсказки

- В играх с открытым полем можно листать ходы назад и вперёд.
- В играх с оценкой позиции доступны график партии и отметки ошибок. В Кворидоре есть подсказка хода и разбор вариантов.
- В разборе можно сходить самому с любой позиции (вариант) и посмотреть, что скажет движок, а потом вернуться к партии или продолжить игру с этого места.
- В онлайн-партии движка нет совсем: ни оценки, ни подсказок. После её конца разбор доступен обоим.
- Координаты включаются кнопкой «a1». Координаты, история и переворот — личные настройки устройства.

## Сдача и ничья

Во всех одиннадцати играх во время партии есть белая кнопка «Сдаться» с подтверждением
и «Предложить ничью». Боты всегда принимают ничью сразу, независимо от позиции
и сложности. Люди принимают или отклоняют её каждый за себя; на одном устройстве
ответы запрашиваются по очереди. В точках, лаве и Кворидоре на четверых сдача убирает только одного
участника, остальные продолжают. Для ничьей нужно согласие всех оставшихся людей.
Ход, окончание партии или потеря связи отменяют незавершённое предложение.
После результата доступна новая партия, а в играх с открытым полем — анализ; результат восстанавливается
при переподключении. В шахматном PGN и шашечном PDN сохраняется итог партии.

Общая логика: `src/shared/match-core.js`, `match-actions.js`, `match-actions.css`;
адаптер каждой игры: `src/<игра>/match.js`. Сетевые решения принимает хозяин,
место отправителя определяется соединением. Проверки: `npm run test:match`
(Edge, свободные порты 9008 и 9009), правила и голосование — `npm test`.

## Без интернета

Достаточно один раз открыть сайт с интернетом: все игры сохранятся на устройстве. Потом с ботами и вдвоём
на одном экране можно играть без сети. На телефоне сайт можно добавить на главный экран как приложение
(Android: «Установить» на главной; iPhone: «Поделиться» → «На экран „Домой“»).

## Правила коротко

- **Дурак:** по шесть карт из колоды на 36 или 52. В переводном атаку можно передать следующему игроку картой того же достоинства. В онлайне можно включить мухлёж и проверять карты, которыми отбился соперник.

- **Кворидор:** доберись до противоположного края 9×9. За ход передвинь фишку или поставь стену. У каждого игрока должен остаться путь к цели.

- **Точки:** тапаешь свою клетку, и в ней прибавляется точка. Клетка взрывается на 4 точках (в середине), 3 (у края) или 2 (в углу) и захватывает соседей.
- **Крестики-нолики 3×3:** клетка, куда ты сходил, задаёт доску для соперника. Выиграл маленькую доску, и она твоя. Побеждает тот, у кого три доски в ряд.
- **Морской бой:** поле 10×10, флот 4-3-3-2-2-2-1-1-1-1, корабли не касаются. Попал, значит стреляешь ещё.
- **Го (китайские правила):** камни ставят на пересечения; группа без свободных соседних пунктов снимается; самоубийство и повтор позиции (ко) запрещены; два паса — конец; счёт — камни плюс окружённая территория, белым коми 7.5.
- **Русские шашки:**
  - бить обязательно (можно выбрать любой вариант взятия);
  - простая шашка бьёт назад;
  - дамка дальнобойная;
  - превращение посреди взятия;
  - турецкий удар.

## Лава

Поле всегда 6 × 6 и целиком из плиток. Плитки бывают трёх видов: белая выдерживает
3 прыжка, бежевая — 2, тёмная — 1, потом на её месте лава. Карты отличаются только
тем, где какие плитки: «Классика» (как в оригинальной игре), «Кольцо», «Крест»,
«Углы», «Диагонали», «Ядро» и «Случайная» (новая симметричная каждый раз).
Игроки стартуют на бежевых плитках во внутренних углах. Цвета закреплены за углами:
фиолетовый слева сверху, зелёный справа сверху, синий справа снизу, красный слева снизу;
ходят по часовой. Для каждого угла выбирается: игрок на этом устройстве, бот,
друг по сети или пусто (2–4 участника); первый ход — по цвету или случайно.

Ход — прыжок по прямой (вверх, вниз, влево, вправо) на **любое расстояние**:
пролетать можно над фишками и лавой, приземляться — только на плитку. Плитка,
**с которой** прыгнул, теряет слой. Назад — туда, откуда прилетел (или откуда тебя
толкнули), — нельзя; стрелки на фишке показывают разрешённые стороны. **Прыжок на
месте** снимает запрет и тоже ломает свою плитку (на последнем слое — сгоришь).
Прыжок на соперника **толкает** его и всех, кто стоит за ним вплотную, на клетку
дальше; попавший в лаву сгорает. Если за толкаемыми стена, толчок не проходит, а
прыгнувший отскакивает на клетку перед ними (если там лава — сгорает сам).
Побеждает последний оставшийся.

Управление: тап по клетке, куда прыгаешь, или перетаскивание фишки (подсветки ходов нет);
два тапа по своей фишке (или кнопка «На месте», пробел) — прыжок на месте.
Ход можно вернуть: с ботами — сразу (до последнего хода человека), онлайн — если согласны
все остальные люди за столом (боты не спрашиваются). Под полем — перемотка ⏮ ◀ ▶ ⏭ как в
остальных играх; в просмотре можно сыграть вариант, а кнопка возврата хода становится
«Играть с этой позиции». История партии хранится в состоянии (start + log).
Локальная партия сохраняется и продолжается из меню; без интернета тоже работает.

Онлайн: выбери себе угол «Игрок», друзьям — «Друг», создай игру, отправь одну
ссылку каждому и начни после подключения всех. Гости могут пересесть в свободный
угол до старта. Можно добавить ботов: их ходы считает хозяин. Несколько локальных
игроков также могут играть с одного устройства. Всего — до четырёх участников.
В общей комнате хаба — двое,
как и в других играх; для 3–4 открой `/lava/` отдельно. Хозяин проверяет ходы,
очередь, номер хода и номер партии, затем рассылает состояние. При потере связи
с живым игроком партия ждёт его возвращения; его место сохраняется. Для
возвращения используй ту же вкладку/код. Если хозяин закрыл страницу, партия
не восстанавливается. Реванш начинает хозяин после окончания, когда все на связи.

Исходники: `src/lava/core.js` (правила и карты), `net.js` (сеть), `app.js` (интерфейс),
`art.js` (SVG-графика), `style.css` и `ui.html`.
Проверки правил, ботов и сетевого протокола: `node --test tests/lava*.test.cjs`.
Общие часы и анализ шести классических игр в «Лаве» не используются.
В общей комнате хаба партия начинается сама, как только друг подключился.


## Часы и шахматы

Во всех шести играх в меню есть карточка «Время на партию»: «Без часов», готовые
контроли 1+0, 3+2, 5+3, 10+5, 15+10, 30+0 или «Своё» — минуты и добавка кнопками −/+,
а галочка «Разное время игрокам» даёт фору (своё время каждому цвету/месту).
В онлайне настройки выбирает хозяин, его часы являются источником истины.
Прибавка начисляется за каждый завершённый ход (в морском бое — выстрел).
Расстановка флота без времени. В Точках часы стоят, пока идёт анимация взрывов.
Просмотр истории, фон и потеря связи часы не останавливают; отмена хода не
возвращает время. При первой просрочке партия заканчивается, в том числе в
Точках на 3–4 игроков.

Шахматы (`/chess/`): со Stockfish 19 (полная сила), вдвоём, онлайн и комната, «Доска для анализа» из меню.
Рокировка, взятие на проходе, выбор превращения, мат, пат, автоматическая ничья по троекратному
повторению/50 ходам/недостатку материала; предложение ничьей (Stockfish соглашается, если у него нет
перевеса; онлайн — друг отвечает), сдаться, отмена хода (онлайн — по согласию).
Справа от доски (на телефоне — под ней) панель анализа с тремя вкладками:
- «Движок» — Stockfish: оценка, глубина, три лучшие линии, стрелка лучшего хода; тап по линии — сыграть;
- «Дебюты» — база партий мастеров из The Week in Chess (классика, оба 2300+): название дебюта, ходы
  со статистикой 1–0 / ½ / 0–1, партии сильнейших — открываются на доске;
- «Нотация» — ходы партии с вариантами; с любой позиции можно сходить и посмотреть (вариант).
В онлайн-партии движка и базы нет, после её конца — у обоих.
Режим «Вслепую»: фигур на доске не видно, ходы тапами, кнопка с глазом — подсмотреть, пока держишь.
Координаты — только по краям (буквы снизу, цифры слева), онлайн общие.
Шахматные правила: chess.js 1.4.0 (BSD-2-Clause, `src/chess/LICENSE`).
Движок: Stockfish 19 (stockfish.js lite single-threaded WASM), GNU GPL v3, `src/chess/sf/`.
Фигуры: набор cburnett (Colin M.L. Burnett), GPLv2+, `src/chess/PIECES-LICENSE.txt`.
База дебютов: `python3 tools/build_openings.py 1270 1669 <путь к lichess-org/chess-openings>` — скачивает выпуски
TWIC и пишет `src/chess/db/` (названия дебютов — lichess-org/chess-openings, CC0).

На каждой странице игры слева сверху есть кнопка «← Все игры» (в комнате её нет —
там своя панель «← Игры»).

Проверка: `node --test tests/*.test.cjs`, затем `python build.py`.

Браузерные проверки (Windows / Edge): `npm install`, `python build.py`, `npm run test:browser`. Проверяются два независимых окна, все шесть игр, синхронизация часов и результат просрочки. Порты 8765, 8766, 9000 должны быть свободны.

Если Windows сообщает `No time zone found with key Europe/Vienna`, установите базу часовых поясов: `python -m pip install tzdata`.


## Навигация и оценка

На каждой странице игры есть подписанный выход «Все игры». В общей комнате
используется кнопка «Игры» на панели комнаты.
«С оценкой / Без оценки» выбирается до начала партии и фиксируется для неё.
Без оценки во время партии скрыты полоса и подсказки, в том числе в истории;
после окончания доступен разбор. Онлайн-партия всегда без подсказок.
В шахматах используется английская SAN (K, Q, R, B, N); оценка видна рядом
с нотацией. В морском бое полоса показывает шанс попадания лучшим выстрелом,
а не вероятность победы.
Проверки настройки и выхода: `npm run test:preferences` (Edge).


## Выбор игры в комнате

Любой из двух участников может предложить игру из каталога. Другой участник
принимает или отклоняет запрос. До согласия обоих текущая партия сохраняется
и продолжает идти (включая часы). Автор может отменить запрос; через 30 секунд
запрос истекает. При потере связи запрос снимается. Новая игра открывается
у обоих после подтверждения; новый код комнаты не нужен.
Проверка двух браузеров: `npm run test:room` (Edge; порт 9002 свободен).


## Анализ своей позиции и онлайн-база Lichess

Кнопка «Анализ» открывает свободную доску без часов и соперника.
«Выставить позицию / импорт» позволяет расставить фигуры, убрать фигуры,
выбрать очередь хода и рокировки, загрузить FEN или целую партию PGN.
Stockfish, дерево вариантов и базы работают с выбранной исходной позицией.

Во вкладке «Дебюты» можно выбрать локальную базу мастеров TWIC или
онлайн-базу рейтинговых партий Lichess. Онлайн-фильтры: рейтинг и контроль
времени, включая группы ниже 2300. Доступны статистика продолжений,
недавние партии и открытие полной партии на доске анализа.
Официальный API `https://explorer.lichess.org/lichess` требует личный токен
Lichess без дополнительных scopes. Создать его можно по ссылке в интерфейсе.
Токен живёт только в памяти вкладки, не сохраняется в localStorage и не входит
в исходники. Запросы идут только в Lichess. После перезагрузки нужно подключиться
заново. Есть кеш запросов, задержка при смене позиции, обработка 401/429 и
переключение обратно на локальную базу. Сервис Lichess нужен только онлайн-базе.
Данные Lichess: https://database.lichess.org/ (CC0).
Спецификация: https://github.com/lichess-org/api/blob/master/doc/specs/tags/openingexplorer/lichess.yaml

Проверки: `npm run test:study`. Проверяются редактор, импорт, нестандартная
исходная позиция, фильтры и выбор ходов; ответы внешнего API в этих проверках
подменяются контролируемыми данными, включая ошибки авторизации.


## Сохранение PGN и общие шансы в Точках

В шахматах кнопка «Экспорт PGN» доступна во время партии и в анализе.
Можно скачать всю партию с рекурсивными вариантами либо ветку до текущей
позиции. Сохраняются начальный FEN (SetUp/FEN), результат и известные данные
игроков/источника. На телефонах с Web Share API есть «Поделиться файлом»;
в остальных браузерах — обычное скачивание `.pgn`.

В Точках при включённой оценке одновременно показываются все активные места
(2–4): цветные доли и подписи с процентами, в сумме 100%. У выбывших — 0%.
Это относительная эвристическая оценка поиска, а не статистически гарантированная
вероятность. Общий бюджет оценки делится между игроками; боты не менялись.
История и варианты показывают распределение для соответствующей позиции;
во время онлайна оценка по-прежнему скрыта.
Проверка скачивания и интерфейса: `npm run test:export`.


## Оценка и стрелки в шахматах

Над вкладками показывается числовая оценка Stockfish с точки зрения белых:
`+0.30`, `−0.80` или мат `#N`. Кнопка «К» скрывает/показывает оценку,
соседняя кнопка со стрелкой независимо управляет синей подсказкой лучшего хода.
Они работают на всех вкладках: движок, дебюты, нотация. Выбор «Без оценки»
до партии и запрет подсказок во время онлайна сохраняются.

На компьютере правая кнопка мыши рисует зелёные стрелки (или круг на поле).
Повтор той же пометки удаляет её. Esc, левый клик или тап по доске очищают пометки текущей позиции. Пометки личные,
не выполняют шахматные ходы и не исчезают при выключении подсказок движка.
Координаты вынесены за клетки с адаптивным полем для подписей.
Проверки вкладок, переключателей, мыши и размеров: `npm run test:overlays`.


## Русские шашки: премувы и анализ

Шашки можно перетаскивать мышью или пальцем. Серия взятий выполняется по
шагам; превращение в дамку во время серии учитывается. Против бота и друга
можно заранее задать один премув кликами или перетаскиванием. После ответа
он заново проверяется по правилам: обязательное взятие отменяет незаконный
премув; при нескольких путях взятия нужно выбрать путь вручную. Esc или
правый клик отменяют заготовку.

«Анализ партии» открывает доску без часов. Справа (на телефоне — под доской)
находятся нотация с переходами и варианты, а также встроенный движок русских
шашек с числовой оценкой и лучшим ходом. Запрет оценки до начала партии
и запрет подсказок во время онлайн-партии сохраняются.

Экспорт/импорт использует шашечный формат PDN, GameType 25. Можно сохранить
всю партию с вариантами либо текущую ветку; импортировать текст или файл,
включая исходную позицию FEN. Чужие виды шашек и незаконные ходы отклоняются.
На телефоне поддерживается системная отправка файла, если браузер её умеет.
База партий/дебютов пока не встроена: свободная лицензия найденных сборников
не подтверждена. Спецификация PDN: https://wiegerw.github.io/pdn/gametype.html

Проверки: `npm test`, `npm run test:checkers` (Edge, свободный порт 9003).


## Анализ после просрочки и продолжение позиции

После поражения по времени во всех шести играх окно предлагает «Анализ».
Разбор открывается без часов и без ответов прежнего соперника. История
сохраняется; флаг часов не превращает позицию на доске в мат или сдачу.

В шахматах, русских шашках, го и точках есть подписанная кнопка
«Продолжить с этой позиции». Она доступна в анализе и при просмотре истории
офлайн, а в онлайне — после окончания партии. Новая партия берёт выбранную
ветку, включая нестандартный начальный FEN в шахматах/шашках, размер доски
и коми в го, карту и состав исходных мест в точках. Для позиции с уже
завершённой игрой нужно сначала вернуться на предыдущий ход.

В окне запуска выбираются: друг на одном устройстве, бот с уровнем сложности
или онлайн по коду; сторона/цвет, оценка и контроль времени (включая фору).
Часы стартуют заново, старый результат не переносится. В онлайне движок
скрыт; хозяин отправляет исходную позицию и историю, в том числе после
переподключения гостя. В точках онлайн-места живых соперников заполняют друзья.
У крестиков-ноликов и морского боя нового выбора продолжения нет.

Проверка: `npm run test:continue` (Edge; свободный порт 9004).


## Абалон

`/abalone/` — классические правила на шестиугольной доске из 61 лунки.
По 14 шаров; чёрные начинают; победа после шестого выбитого шара соперника.
Сдвиг 1–3 соседних шаров в прямой линии, боковой ход на свободные поля,
сумито 2:1 / 3:1 / 3:2. Равные группы не толкают друг друга. Свои шары
за край не уходят. Правила сверены с инструкцией издателя:
https://foxmind.co.il/wp-content/uploads/2021/10/ABALONE_CLASSIC_RULES_EN-FM-p.pdf

Ползунок в меню показывает 10 расстановок с предпросмотром: первая стандартная,
остальные девять — дополнительные авторские симметричные варианты по 14 шаров.
Можно выбрать шары касаниями и нажать направление, нажать свободную лунку
или перетащить выбранную группу. Промежуточный свой шар между выбранными
концами группы добавляется автоматически. Координаты и нотация едины у обоих.

С ботом доступны шесть сложностей и любой цвет; есть два игрока на одном
устройстве, онлайн по коду/ссылке и общая комната с согласованием выбора игры.
Хозяин проверяет ходы, пересылает расстановку и историю при переподключении;
отмена онлайн требует согласия другого игрока. Общие часы поддерживают
добавку и разное время сторонам; просрочка открывает анализ без часов.

Встроенный движок использует эвристическую оценку, итеративное углубление
и поиск с альфа-бета отсечениями в Web Worker. Он показывает оценку, лучший
ход и синюю стрелку по кнопке подсказки. Есть история, варианты, отдельный
анализ и «Продолжить с этой позиции» с выбором соперника и свежих часов.
При «Без оценки» подсказки скрыты и в истории; во время онлайна их нет.

Исходники: `src/abalone/core.js`, `ui.html`, `style.css`, `app.js`.
Сборка: `python build.py`. Проверки правил: `node --test tests/abalone.test.cjs`;
браузер/две вкладки/комната/часы/телефон: `npm run test:abalone` (Edge,
порт 9005 свободен). Новая страница включена в общий офлайн-кеш.


## Личный вид доски и «Четыре в ряд»

По умолчанию оценка, координаты и список ходов выключены. Обновление один раз
переводит старые сохранённые настройки в эти значения; последующий явный выбор
сохраняется. Кнопки справа сверху: переворот, координаты и ходы. Вид хранится отдельно для каждой вкладки (sessionStorage), в том числе после перезагрузки. Их состояние
не передаётся по сети. Настройки координат из старых сетевых пакетов игнорируются.
Второй игрок видит свою сторону снизу; в точках/лаве верхний стартовый угол
разворачивается вниз. Переворот остаётся личным и сохраняется при ходах.
В шахматном анализе кнопка переворота также стоит рядом с оценкой и стрелками.

Абалон: управление свайпом подхватывает до трёх своих шаров в линии от крайнего
шара; явно выбранная пара или тройка сдвигается целиком. Переход длится 280 мс,
включая толкаемые шары. Живой экран без панели управления и подсказки; по
кнопке «Ходы» можно отдельно открыть нотацию. Координаты вынесены на края.
Подсказка и панель движка доступны в анализе. Целевые глубины уровней:
лёгкий 2, средний 3, сильный 5, эксперт 10, мастер 15; максимум — итеративный
поиск до лимита времени (8.5 с), такой же, как анализ. Полный список ходов,
альфа-бета и таблица транспозиций; фактически завершённая глубина показывается
по мере поиска. Временной бюджет означает, что целевая глубина не гарантируется
на каждой позиции и каждом устройстве. Движок не является доказанно непобедимым.

`/falling4/`: поле 7×6, фишки падают в самый нижний свободный слот; четыре
по горизонтали, вертикали или диагонали дают победу, полное поле — ничью.
Есть бот трёх уровней, два игрока, онлайн и общая комната, часы, анализ,
варианты и продолжение позиции. Личный переворот отражает поле слева направо,
сохраняя падение сверху. Правила: https://instructions.hasbro.com/en-ca/instruction/connect-4-game-instructions

Проверки: `npm test`, `npm run test:view`, `npm run test:updates` (Edge,
порт 9007). Проверяются свайпы касанием, плавный сдвиг групп, падающие фишки,
зеркальные старты и независимые настройки у двух участников во всех играх.
