# Игры на двоих

Три игры в браузере: с ботом, вдвоём на одном экране или онлайн с другом по ссылке.

Играть: https://maximdibrova-netizen.github.io/TicTacToe/

| Игра | Адрес | Режимы |
|---|---|---|
| Крестики-нолики 3×3 (Ultimate) | `/ttt/` | бот, вдвоём, онлайн |
| Морской бой | `/battleship/` | бот, онлайн |
| Русские шашки | `/checkers/` | бот, вдвоём, онлайн |

## Правила коротко

- **Крестики-нолики 3×3:** клетка, куда ты сходил, задаёт доску для соперника; выиграл маленькую доску — она твоя; побеждает три доски в ряд.
- **Морской бой:** поле 10×10, флот 4-3-3-2-2-2-1-1-1-1, корабли не касаются; попал — стреляешь ещё.
- **Русские шашки:** бить обязательно (можно выбрать любой вариант взятия), простая бьёт назад, дамка дальнобойная, превращение посреди взятия, турецкий удар.

## Как устроено

- `src/<игра>/core.js` — правила и бот, `src/<игра>/ui.html` — страница
- `src/shared/net.js` — онлайн на двоих (PeerJS, прямое соединение браузеров)
- `src/hub.html` — главная страница со списком игр
- `build.py` — собирает `index.html`, `ttt/`, `battleship/`, `checkers/`
