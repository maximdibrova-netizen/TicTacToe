# Крестики-нолики 3×3

Девять досок в крестики-нолики, собранных в одну большую 3×3.

Правила Ultimate tic-tac-toe:

- Первый ход — в любую клетку. Дальше клетка, в которую ты сходил, задаёт доску, где ходит соперник.
- Если эта доска уже выиграна или заполнена, соперник ходит в любую открытую доску.
- Три в ряд на маленькой доске — она твоя. Заполнилась без победителя — не засчитывается никому.
- Побеждает тот, кто соберёт три своих доски в ряд на большом поле. Если не вышло ни у кого — ничья.

Режимы: с ботом (лёгкий, средний, сильный), вдвоём на одном экране, онлайн с другом по ссылке. Есть отмена хода (в онлайне — по согласию).

Играть: https://maximdibrova-netizen.github.io/TicTacToe/

## Как устроено

- `src/core.js` — правила и бот (поиск с альфа-бета-отсечением)
- `src/ui.html` — интерфейс, звук, онлайн (PeerJS, прямое соединение браузеров)
- `build.py` — собирает `index.html`
