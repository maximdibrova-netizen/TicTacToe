# Крестики-нолики 3×3

Девять досок в крестики-нолики, собранных в одну большую 3×3.

- Ходите по очереди, ставить можно в любую свободную клетку любой незанятой доски.
- Три в ряд на маленькой доске — она твоя. Заполнилась без победителя — ничья, ни за кем.
- Побеждает тот, кто соберёт три своих доски в ряд на большом поле.

Режимы: с ботом (лёгкий, средний, сильный), вдвоём на одном экране, онлайн с другом по ссылке. Есть отмена хода (в онлайне — по согласию).

Играть: https://maximdibrova-netizen.github.io/TicTacToe/

## Как устроено

- `src/core.js` — правила и бот (поиск с альфа-бета-отсечением)
- `src/ui.html` — интерфейс, звук, онлайн (PeerJS, прямое соединение браузеров)
- `build.py` — собирает `index.html`
