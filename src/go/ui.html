Онлайн с другом

Цвет и доска хозяина берутся из настроек выше. В реванше цвета меняются.

Правила

  1. Чёрные ходят первыми. Камень ставят на пересечение линий, двигать его потом нельзя.
  2. Камни одного цвета, стоящие рядом по линиям, — одна группа. Её дамэ — соседние пустые пункты.
  3. Заняли последнее дамэ группы — она снимается с доски. Ход, после которого своя группа остаётся без дамэ, запрещён (если он ничего не съедает).
  4. Ко: нельзя повторять позицию на доске — сразу отбить единственный камень нельзя, нужно сходить в другом месте.
  5. Можно спасовать. Два паса подряд — конец партии. Мёртвые камни снимаются, их можно отметить тапом.
  6. Счёт: свои камни + окружённая пустая территория. Белые получают 7.5 очка коми за второй ход.
